Raid Tools 1.4.0 - Ako/Defou1t (from Norrina-Hub by Norrina)
(до 1.4.0 - Raid & Fish Tools; папка по-прежнему RaidFishTools)

FISH TRACKER ПЕРЕЕХАЛ в Auction Income 1.10.0 (кнопка "Fish: On/Off" в его
главном окне). update-addons.cmd сам поставит Auction Income, если его нет.

ОБНОВЛЕНИЕ - дважды кликните update-addons.cmd в этой папке: скачает последние
версии Raid Tools и Auction Income, сначала сохранив копию в
Addon\_backups\<дата>. whitelist.txt, настройки и записи не затираются.

КНОПКА "Raid Tool" - окно рекрутинга (Shift + перетаскивание двигает кнопку).

ПЕРЕДАЧА ЛИДЕРА - кодовое слово по умолчанию у всех gmlr (можно поменять в окне).
Игрок из списка lead пишет gmlr в чат рейда/группы и получает лидера.

ВАЙТЛИСТ - файл whitelist.txt в этой папке (RaidFishTools\whitelist.txt).
Окно показывает этот файл и пишет в него:
  поле "Whitelist"            = все ники файла, кроме lead;
  поле "Give lead whitelist"  = ники из lead.
Правьте где удобнее: в окне (Save записывает файл) или в Блокноте (при
открытии окна или по "Reload file" ники подтянутся). Лимита на число ников
нет. Если игра всё же обрежет длинный список в поле, Save этот список не
тронет - тогда правьте его в Блокноте.
Создаётся сам при первом запуске; образец - whitelist.example.txt.
Формат (кавычки и запятые обязательны):

{
    lead = {
        "Name1",
        "Name2",
    },
    invite = {
        "Name3",
        "Name4",
    },
}

  lead   - кому можно передать лидера рейда кодовым словом;
  invite - кого приглашать при "Whitelist Only: ON". Ники из lead тоже
           приглашаются.
Можно добавлять и свои группы, например  Guild = { "Name5", "Name6" },  -
они считаются как invite, и Save их сохраняет. Регистр букв не важен.
Рядом с "Reload file" видно, сколько ников загружено: "File: 9, lead 1".
Ники, вписанные в окне до 1.4.0, при первом запуске переносятся в файл.

Настройки окна хранятся в Addon\raidfish_data.lua.
